FINTRACK WEB FINANCE TRACKER

Run:
1. Install Flask:
   py -m pip install flask
2. Open this folder in a terminal.
3. Run:
   py app.py
4. Open the address shown by Flask (normally http://127.0.0.1:5000).

IMPORTANT:
- The original project is preserved under original-project/CLI Project.ipynb.
- The web UI files are separate.
- app.py is the connector for the browser interface.
- Download CSV creates fintrack_transactions.csv from the finance data.
- If you need the exact original CLI notebook behavior preserved, do not edit the notebook.
